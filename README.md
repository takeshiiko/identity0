# Identity.0

Deterministic wallet-derived Bauhaus NFT collection monorepo.

## Quick Start

```bash
npm install
npm run dev
```

## Workspaces

- `apps/web`: Next.js 14 frontend
- `apps/contracts`: Hardhat Solidity contracts
- `packages/wallet-analyzer`: wallet scoring engine
- `packages/geometry-engine`: deterministic procedural SVG engine
- `packages/ai-pipeline`: Replicate SDXL/ControlNet pipeline
- `packages/shared`: shared types, constants, ABI/address exports
- `services/api`: Express, BullMQ, Redis, Prisma API service
